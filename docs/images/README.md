# README ekranları

Bu qovluqdakı fayllar GitHub README-si üçün təqdimat materiallarıdır.

Ekranlar mövcud Android test çəkilişlərindən götürülüb və iPhone üslubunda çərçivəyə yerləşdirilib. Bunlar real iPhone çəkilişi və ya iOS simulyatorunun görüntüsü deyil. İnterfeys mətnləri və nümunə məlumatlar dəyişdirilməyib.

Telefon çərçivəsi və üz qabığı bu repo üçün hazırlanıb. WebP faylları README-ni lazımsız ağırlaşdırmadan mətn və şəkillərin oxunaqlılığını saxlamaq üçün istifadə olunur.

Görüntülər nümunə kataloqa aiddir; real istifadəçi məlumatı və giriş açarları daxil edilməyib. Sonrakı UI dəyişikliklərində uyğun ekranları yeniləmək lazımdır.
